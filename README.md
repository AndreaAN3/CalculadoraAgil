# CalculadoraAgil

## Actividad 4. Simulación de un Proyecto Ágil

### Descripción
CalculadoraAgil es una aplicación de escritorio desarrollada en Java utilizando la biblioteca Swing. Permite realizar operaciones matemáticas básicas mediante una interfaz gráfica sencilla e intuitiva.

### Objetivo
Desarrollar una aplicación funcional aplicando los principios de la metodología ágil Scrum, simulando los roles de Product Owner, Scrum Master y Developer.

### Funcionalidades
- Suma de dos números.
- Resta de dos números.
- Multiplicación de dos números.
- División de dos números.
- Validación de datos numéricos.
- Manejo del error de división entre cero.
- Interfaz gráfica desarrollada con Java Swing.

### Tecnologías utilizadas
- Lenguaje: Java.
- Interfaz gráfica: Java Swing.
- Entorno de desarrollo: Apache NetBeans 31.
- Control de versiones y publicación del código: GitHub.

### Instalación y ejecución
1. Descarga o clona este repositorio.
2. Abre el proyecto en Apache NetBeans.
3. Comprueba que el archivo `CalculadoraAgil.java` esté dentro del paquete correspondiente.
4. Ejecuta la clase `CalculadoraAgil`, que contiene el método `main`.
5. Introduce dos números y selecciona la operación deseada.
